토지조서베타

구역계만 넣으면 최신 지적도를 받아 잘라 내고, 편입 필지의 지목 · 공부상 면적 · 소유구분 · 개별공시지가로 토지조서를 만듭니다.

구역계→엑셀 · DXF · SHP
  • QGIS 자르기와 같은 편입면적 · 완전/부분편입 자동 판정
  • 지목별 · 소유구분별 요약표 (발표자료용)
  • 엑셀 · 편입도면 DXF · SHP · GPKG

농지 · 산지 조서베타

구역계를 넣으면 편입 농지 · 임야를 찾아 농지구분 · 산지구분과 공시지가로 농지보전부담금 · 대체산림자원조성비 조서와 전용협의도를 만듭니다.

구역계 · 토이계→엑셀 · DXF
  • 토지이용계획 해치로 시설별 면적 안분 · 감면 (합계 검산)
  • 농업진흥지역 안 · 밖, 보전 · 준보전산지 나눠 계산
  • 토지대장 PDF 로 소유자 확인 (PC 안에서만 · 직접 확인한 필지만)
  • 농지 · 산지 전용협의도 DXF

관리계획도베타

구역계를 넣으면 용도지역 · 지구 · 도시계획시설 · 도로를 받아(또는 내 SHP) 결정사항 도장이 찍힌 관리계획도(기정) CAD 와 UPIS 결정조서를 만듭니다.

구역계 · SHP→DXF · DWG · 엑셀
  • 지침 표시기준 해치 · 도장 · 배치탭 도곽 · 범례
  • 시설마다 근거 고시 찾기 · 고시문 PDF 로 결정조서 채우기
  • UPIS 조서등록양식(xlsx)

현황분석베타

구역계만 고르면 위치도 · 토지이용 현황도 · 지목 현황도를 만듭니다. 일러스트레이터에서 바로 고칠 수 있게 묶음 · 레이어가 정리되어 나옵니다.

구역계→SVG · PNG · 엑셀
  • 용지 크기 자유 (A4~A0 · 직접 입력) · SVG · PNG · JPG
  • 지도 범위 · 반경 자동 · PPT 에 넣고 그룹을 풀어도 그대로
  • 도로번호 표지 · 철도 · 지하철 노선 이름표 · 주요 시설은 종류별로 묶음
  • 지목별 면적표 엑셀

지적도베타

지적 SHP(또는 구역계 → 브이월드)의 필지마다 지번을 필지 방향 · 크기에 맞춰 가운데에 넣은 DXF · DWG 를 만듭니다.

지적 SHP→DXF · DWG
  • 지번은 SHP 값 그대로 · 좌표도 SHP 그대로
  • 세로 · 대각선 필지는 글자도 그 방향으로
  • 이 PC 의 글꼴에서 고르기 (글자 폭 자동 맞춤)

도면 종합툴

수치지형도 도엽(DXF·DWG)을 한 장으로 합치고, 좌표계를 바꾸고, 표고·경사를 분석합니다.

DXF · DWG→DXF · 엑셀
  • 겹친 객체 정리 · 레이어 범례 일괄 변경
  • GRS80 ↔ Bessel · UTM-K · 원점 간 변환
  • 표고·경사 분석표(엑셀) · 삽도(DXF) · GIS 파일 (표고만 · 경사만도)
  • 구역계 안 값만 따로 정리

용도지역 → CAD

용도지역 SHP(UQ111)를 「도시·군관리계획수립지침」 도면 표시기준(1/5,000)에 맞춘 해치 도면으로 바꿉니다.

SHP→DXF
  • 21개 용도지역 바탕색 · 사선 · 원 무늬
  • 제2종일반주거 '7층이하' 레이어 따로
  • 여러 SHP 를 한 도면으로

지목 → CAD

연속지적도 SHP 의 지목 부호로 28개 지목을 나눠, 지목별 색 해치 도면으로 바꿉니다.

SHP→DXF
  • 지번 끝 글자(대 · 전 · 답 …)를 바로 읽음
  • 여러 시군구를 한 도면으로 (같은 필지는 한 번만)

소유구분 → CAD

소유자 값을 국유지 · 공유지 · 사유지로 나눠 색 해치 도면으로 바꿉니다.

SHP→DXF
  • '국(국토교통부)' · '경기도 광주시' 같은 값도 알아봄
  • 관리청별 · 지자체별 세부 레이어

PPT 그림 바꾸기

파워포인트에서 필요한 부분만 잘라 둔 그림을, 자른 범위 · 위치 · 효과는 그대로 두고 새로 내보낸 그림으로 바꿉니다.

PPT→PPT
  • 열린 PPT 에 바로 (저장 · 다시 열기 없이)
  • 대지 · 플롯 범위 · 해상도가 달라도 같은 부분을 자동으로 찾기
  • 애니메이션 · 테두리 · 앞뒤 순서 그대로
  • 그룹 안 그림 · 도형 자리에도
SHP → CAD 도구 3종은 QGIS 스크립트와 같은 규칙으로 만들어, 같은 SHP 로 QGIS 에서 만든 DXF 와 똑같은 결과가 나옵니다. QGIS 는 없어도 됩니다.

위치도, 클릭 몇 번이면

구역계를 넣으면 주변 철도 · 도로 · 반경을 알아서 그립니다.

  • PPT 에 넣고 그룹을 풀어도 글자가 깨지지 않는 SVG
  • 지하철 노선 색 · 환승역 표시 · 도로번호 표지
  • 지도 밖 요소는 넣지 않아 일러스트에서도 깔끔

SHP 를 CAD 도면으로

용도지역 · 지목 · 소유구분을 지침 표시기준에 맞춘 해치 도면으로 바꿉니다.

  • 저장하기 전에 레이어별 개수 확인
  • 여러 시군구 SHP 를 한 도면으로
  • DXF · DWG (정품 CAD 또는 무료 변환기가 있으면)

시작하기

설치는 필요 없습니다. 3단계면 끝납니다.

1

내려받기

위의 무료로 내려받기를 누르면 항상 최신 버전이 받아집니다.

2

압축 풀고 실행

압축 파일을 오른쪽 클릭 → 모두 압축 풀기 한 뒤 AzazaTool.exe 를 실행합니다. “PC 보호” 화면이 나오면 추가 정보 → 실행.

3

회원가입

이름 · 업계 · 아이디 · 비밀번호로 가입합니다. 허가되면 이후로는 자동으로 로그인됩니다.

자주 묻는 질문

정말 무료인가요?

네. 회원가입만 하면 무료로 쓸 수 있습니다.

여러 PC 에서 써도 되나요?

한 계정으로 PC 2대까지 쓸 수 있습니다 (예: 회사 PC + 노트북). 3번째 PC 에서 로그인하면 가장 오래 안 쓴 PC 가 로그아웃됩니다. 인터넷이 없어도 마지막 확인 뒤 14일까지 쓸 수 있습니다.

업데이트는 어떻게 하나요?

따로 할 필요가 없습니다. AzazaTool 을 켤 때 새 버전을 확인해 받아 두고, 닫을 때 바꿉니다. 이 페이지의 다운로드 버튼도 항상 최신 버전을 받습니다.

예전에 받은 '도면 종합툴'(DrawingTool.exe)은요?

켜면 자동으로 AzazaTool 로 업데이트됩니다. 쓰던 바로가기(DrawingTool.exe)를 눌러도 AzazaTool 이 열립니다. 로그인 정보도 그대로입니다.

DWG 파일도 되나요?

PC 에 AutoCAD(LT 제외) 등 정품이나 무료 ODA File Converter 가 있으면 DWG 를 읽고 쓸 수 있습니다. 없으면 DXF 로 작업합니다.

첫 화면이 하얗게 나오거나 안 떠요

첫 화면은 윈도우에 들어 있는 Microsoft Edge WebView2 로 그립니다. 이게 없는 PC 에서는 자동으로 간단한 화면으로 열리고, 기능은 같습니다.

탈퇴하면 정보는 어떻게 되나요?

AzazaTool 설정 → 계정 → 회원 탈퇴를 누르고 비밀번호를 넣으면, 서버에 있는 이름 · 아이디 · 소속 · PC 목록 · 사용 기록이 바로 모두 지워집니다. 내 PC 에 저장한 결과 파일은 그대로 남습니다.
