도시·토목·교통 등 엔지니어링 업계 실무자들을 위한 도구 모음 (Windows 10·11, 무료)

## 들어 있는 도구

| 도구 | 하는 일 |
|---|---|
| **도면 종합툴** | 수치지형도 도엽(DXF·DWG) 합치기 · 좌표 변환(GRS80↔Bessel·UTM-K·원점) · 표고·경사 분석표와 삽도(표고만 · 경사만, 경사 구간 자동) · 구역계 안 값 정리 |
| **토지조서** (베타) | 구역계만 넣으면 최신 지적도(브이월드 오픈API)로 편입 필지의 지목·공부상 면적·소유구분·개별공시지가 토지조서 · 요약표 · 편입도면 |
| **농지 · 산지 조서** (베타) | 구역계 → 편입 농지 · 임야의 농지구분 · 산지구분 · 공시지가로 농지보전부담금 · 대체산림자원조성비 조서(엑셀)와 전용협의도(DXF), 토지이용계획 해치로 시설별 면적 안분 · 토지대장 PDF 로 소유자 확인 |
| **관리계획도** (베타) | 구역계 → 용도지역 · 지구 · 도시계획시설 · 도로(브이월드 오픈API 또는 내 SHP)로 결정사항 도장이 찍힌 관리계획도(기정) DXF · DWG 와 UPIS 결정조서, 근거 고시 찾기 |
| **PPT 그림 바꾸기** | 파워포인트에서 잘라 둔 그림을 자른 범위 · 위치 · 효과 그대로 새 그림으로 (열린 PPT 에 바로, 대지가 달라도 자동으로 찾기 · 도형 자리 · 그룹 안 그림도) |
| **현황분석** (베타) | 구역계만 고르면 위치도 · 토지이용 현황도 · 지목 현황도를 SVG · PNG · JPG 로 (용지 크기 자유, 일러스트레이터에서 고치기 쉽게 묶음 정리) · 지목 면적표 엑셀 |
| **지적도** (베타) | 지적 SHP(또는 구역계 → 브이월드 오픈API) 필지마다 지번을 필지 방향 · 크기에 맞춰 가운데에 넣은 DXF · DWG (지번 · 좌표는 SHP 그대로, 글꼴은 PC 글꼴에서 고르기) |
| **용도지역 → CAD** | 용도지역 SHP(UQ111)를 「도시·군관리계획수립지침」 도면 표시기준(1/5,000)에 맞춘 해치 DXF 로 |
| **지목 → CAD** | 연속지적도 SHP 를 28개 지목별 색 해치 DXF 로 |
| **소유구분 → CAD** | 소유자 값을 국유지·공유지·사유지로 나눈 색 해치 DXF 로 |

## 시작하기

1. 위의 **최신 버전 다운로드** 를 누릅니다.
2. 압축 파일을 오른쪽 클릭 → **모두 압축 풀기** → 폴더 안의 `AzazaTool.exe` 실행
   (“PC 보호” 화면이 나오면 **추가 정보 → 실행**)
3. 회원가입(이름 · 업계 · 아이디 · 비밀번호) → 허가되면 자동 로그인

- 한 계정으로 PC 2대까지 쓸 수 있습니다.
- 새 버전은 자동으로 받아 바뀝니다. 예전 `DrawingTool.exe`(도면 종합툴)도 켜면 AzazaTool 로 바뀝니다.

> 브이월드 오픈API로 받은 자료는 측량으로 확정된 실제 경계나 원본 데이터와 다를 수 있습니다. 고시용 도면에는 브이월드에서 직접 받은 SHP, 지자체 SHP 또는 측량 성과를 사용해 주세요.
